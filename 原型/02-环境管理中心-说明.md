# 环境管理中心 页面说明

- 会话：# Camoufox 控制台 UI 功能设计
- 页面角色：主页面
- 导出时间：2026/7/29 22:52:59

【页面职责】
该页面作为指纹浏览器控制台的核心主入口（环境管理中心），主要承担浏览器环境（Profile）的生命周期管理、状态监控和快捷运维职责。用户在此页面可以全局预览所有环境的活跃状态与系统资源占用，进行快速检索、筛选和批量控制，并能在不跳转页面的情况下，通过右侧抽屉对单个选中的环境进行缓存清理、代理重测及指纹配置查看。

【业务对象】
1. 环境（Profile）：核心业务对象，承载了浏览器配置元数据。属性包含环境 ID、环境名称、平台/用途、所属分组、标签、运行状态、最后启动时间。
2. 运行实例（Browser Instance）：环境启动后对应的物理进程，具有不同的运行子状态（未启动、启动中、运行中、API 控制中、运行异常）。
3. 代理（Proxy）：环境绑定的网络代理，属性包含协议、代理地址、物理出口 IP、归属国家/地区、时区、通信延迟及物理位置漂移状态（Phase 2）。
4. 指纹摘要：列表展示格式为 `{OS} · FF {version} · {resolution}`，由 Camoufox 启动时自动生成。

【页面功能说明】
1. 运行状态与存储摘要：页面顶部展示全局环境总数、运行中环境数（含无头实例数）、异常代理警报数、Profile 目录占用与磁盘可用空间，以及本地 Local API 服务运行端口和全局 Camoufox 版本。
2. 环境检索与过滤：支持通过输入环境名、代理 IP、标签或备注进行全局模糊搜索；支持按「分组」、「标签」和「运行状态」进行多条件组合筛选。
3. 批量控制：提供批量启动、批量停止环境以及批量导入环境配置的入口。
4. 快捷启动：顶栏提供最近使用的环境快捷按钮，可一键拉起对应环境。
5. 环境列表网格：以表格形式展示环境基础属性、绑定代理的连通状况、指纹简写、标签分组，并提供行级的启停控制、修改名称、查看详情、Cookie 管理等入口。
6. 快捷管理属性抽屉：选中单一环境时，右侧抽屉支持查看该环境的物理目录空间占用并执行一键清理缓存（仅清理静态文件和历史缓存，保留已登录 Cookie）；查看并一键重新测试出口代理的 GeoIP 实时数据；只读预览指纹配置的 JSON 数据结构。

【关键用户动作与业务含义】
1. 启动 / 批量启动：拉起对应的 Camoufox 浏览器实例，注入指纹与代理配置，业务状态置为启动中/运行中。
2. 停止 / 批量停止：终止运行中的浏览器进程，关闭对应环境，状态变更为未启动。
3. 重试：针对「运行异常」或「启动失败」的环境，重新尝试初始化并拉起浏览器。
4. 强制断开：针对正处于「API 控制中」的自动化任务环境，强制切断 Playwright 连接并杀死浏览器进程。
5. 修改名称：内联修改并更新环境的别名。
6. 一键清理缓存：清空对应环境 Profile 目录下的无用缓存文件，以释放本地磁盘空间，但必须保留用户登录的 Cookie 凭证。
7. 一键重测（代理）：向后端发起代理测试指令，重新获取并更新该代理的出口 IP、地理位置、时区及延迟数据。

【数据与状态流转】
1. 环境运行状态流转：
   - 当用户点击「启动」：环境状态由「未启动」流转为「启动中」；拉起成功后流转为「运行中」或「API 控制中」；若拉起失败或代理异常则流转为「运行异常」/「启动失败」。
   - 当用户点击「停止」/「强制断开」：环境状态由「运行中」/「API 控制中」流转为「未启动」。
2. 代理异常状态流转（Phase 2）：代理检测到出口 IP 实际归属地与预期不一致时，触发「IP 物理漂移」告警。
3. 存储数据更新：用户点击「一键清理缓存」成功后，对应环境的「本地存储空间」数值应实时减小。

【异常与边界情况】
1. 启动锁定：当环境状态为「启动中」时，前台界面会置灰「启动/停止/聚焦」等控制按钮，后端需做好并发控制，防止同一 Profile 目录被重复拉起导致冲突。
2. IP 物理漂移（Phase 2）：实测出口 IP 与预期地理位置不符，后端需记录此异常并向前端输出告警详情。
3. API 进程被锁：当环境显示「API 控制中」时，说明该环境正被外部 Playwright 脚本占用，常规控制按钮不可用，仅能通过「强制断开」来解除占用。

【对后端理解最重要的支撑点】
1. 本地多实例管理：系统是单机/局域网部署，后端需要能高效地启动、监控、聚焦和杀死多个本地 Firefox 进程，并能获取其物理 PID。
2. 物理目录管理：后端需要实现对 Profile 本地存储目录的占用计算，并且「清理缓存」接口在物理删除文件时，必须精确过滤并保留 Cookie 数据库/文件。
3. 实时状态推送：环境状态（如启动中、代理异常、API 占用）变化多端，后端需要通过 WebSocket 实时向前端推送这些实例的运行状态。
4. Camoufox 内核版本为全局 Active，不在环境级别管理。

【页面关系与流程承接】
1. 新建与导入：点击「新建环境」跳转至新建环境向导页（/profiles/new）；点击「批量导入」跳转至批量导入页面（/profiles/import）。
2. 指纹编辑：通过抽屉中的「一键编辑指纹」跳转至指纹策略模板（/fingerprints/:id/edit）。
3. 代理管理：通过列表悬停框或抽屉中的「快捷更换代理」跳转或关联至代理中心模块。
4. 回收站：点击侧边栏「回收站」跳转至已删除环境的回收页面（/profiles/trash）。
5. 详情页承接：点击行操作的「详情」进入单个环境的完整详情页面（/profiles/:id）。
