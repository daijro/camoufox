# 指纹策略模板 页面说明

- 会话：# Camoufox 控制台 UI 功能设计
- 页面角色：子页面
- 导出时间：2026/7/29 22:52:59

【页面职责】
该页面作为指纹策略管理的核心界面，主要用于维护默认策略与高级指纹参数模板。Camoufox 默认在启动时通过 BrowserForge 自动生成指纹；本页面供高级用户管理「固定模板」与全局默认策略。

【业务对象】
1. 指纹策略模板（Fingerprint Template）：包含模板名称、描述、类型（系统预设 / 用户自定义）、是否默认、引用环境数，以及策略参数（OS、Geo 对齐、WebRTC、seed 模式等）。
2. 浏览器环境（Profile）：关联对象，展示每个模板当前绑定的「引用环境数」。

【页面功能说明】
1. 模板检索与计数：支持基于名称、描述或关键字过滤搜索模板；展示系统当前拥有的模板总数及内置预设数量。
2. 模板列表展示：以卡片形式呈展现有的指纹模板。系统预设包括「BrowserForge 自动随机（默认）」和「真实设备预设采样」。
3. 模板基础操作：支持将自定义模板设为默认、复制、编辑；对内置系统模板，仅支持查看与复制。
4. 表单配置（三栏式编辑器中栏）：
   - 基础特征：选择操作系统平台（Windows、macOS、Linux）。User-Agent 只读，启动时自动生成。
   - 屏幕与窗口：配置 DPR、分辨率范围、视口匹配。
   - 地理与 WebRTC：时区/语言跟随代理 IP 开关；WebRTC 策略仅两项——跟随代理 IP 伪装 / 禁用 WebRTC。
   - 指纹噪声 Seed：每次启动随机（默认）或固定 seed（存模板）；字体子集策略。
5. 指纹结构预览与校验（三栏式编辑器右栏）：实时以 JSON 格式预览 camoucfg 结构。

【关键用户动作与业务含义】
1. 新建指纹模板：初始化并向系统注册一个新的策略模板（固定 seed 或高级参数）。
2. 保存模板：将当前编辑器中的策略参数持久化；固定 seed 模式需保存 canvas:seed、audio:seed 等。
3. 随机生成：调用 BrowserForge 重新采样参数（高级模板编辑时）。
4. 设为默认：将选定模板设为全局默认，新建环境时默认引用。

【数据与状态流转】
1. 默认策略：「BrowserForge 自动随机」为系统默认，对应 `launch_options()` 不传 fingerprint 时的行为。
2. 固定模板：保存 camoucfg JSON，每次启动原样注入，seed 不再随机。
3. Geo 联动：启用时区/语言跟随代理时，启动时结合代理 GeoIP 动态写入 timezone、locale 等字段。

【异常与边界情况】
1. 系统内置模板防篡改：BrowserForge 自动随机不可编辑或删除。
2. 被引用模板的修改：引用环境数大于 0 时修改模板，需提示对已绑定环境的影响。

【对后端理解最重要的支撑点】
1. 指纹配置数据结构应对照 `settings/camoucfg.jvv`。
2. 默认行为是 launch 时自动生成，非用户手填 UA。
3. seed 默认每次 launch 随机（见 `utils.py` 中 canvas:seed / audio:seed 赋值逻辑）。

【页面关系与流程承接】
1. 承接入口：侧边导航「指纹配置」；或从「新建环境向导」跳转。
2. 后续流程：保存成功的模板作为「新建环境」中「使用已保存模板」的备选项。
