开发者集成文档

集成 API 到 Playwright（官方支持）。Selenium / CDP 不在 Camoufox 支持范围内。

GET /api/v1/profiles 获取本地保存的所有环境列表
参数字段 类型 是否必填 说明
group_id String 否 按分组 ID 筛选环境
status String 否 按运行状态筛选 (idle/running/error)
POST /api/v1/profiles/{id}/start 启动指定的指纹浏览器实例并返回 WebSocket 地址
参数字段 类型 是否必填 说明
headless Boolean 否 (默认 false) 是否采用无头模式启动浏览器
disable_proxy Boolean 否 (默认 false) 临时禁用该环境绑定的代理网络

Python (Playwright Juggler 自动化连接示例) 
import requests
from playwright.sync_api import sync_playwright

# 1. 触发本地接口服务启动指定浏览器实例
api_url = "http://127.0.0.1:50325/api/v1/profiles/env-983a/start"
headers = {"Authorization": "Bearer cf_live_8f3a..."}
response = requests.post(api_url, headers=headers).json()

ws_endpoint = response["data"]["ws_endpoint"]

# 2. 通过 WebSockets 连接到运行中的 Firefox 进程
with sync_playwright() as p:
    browser = p.firefox.connect(ws_endpoint)
    context = browser.contexts[0] # 获取自动防指纹关联上下文
    page = context.new_page()
    
    # 3. 正常执行自动化业务逻辑
    page.goto("https://bot.sannysoft.com")
    page.screenshot(path="fingerprint_test.png")
    
    browser.close()
