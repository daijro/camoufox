# 批量导入中心 页面说明

- 会话：# Camoufox 控制台 UI 功能设计
- 页面角色：子页面
- 导出时间：2026/7/29 22:52:59

【页面职责】
该页面用于指纹浏览器独立环境（Profile）的批量导入。它允许用户上传包含多个环境信息的外部文件（如 CSV 或 Excel），配置字段映射关系与全局解析规则，并在系统执行格式校验后，预览解析出的数据明细与校验报告，最终将校验通过的环境数据批量持久化至系统。

【业务对象】
1. 环境（Profile）：批量导入的核心创建对象，包含名称、绑定代理、Cookie数据、多标签分组（标签）、备注等属性。
2. 代理（Proxy）：环境依赖的关联对象，根据代理匹配策略，可以与导入环境关联或作为新代理写入代理库。
3. 导入文件（File）：包含待导入环境数据的外部介质，支持 CSV 和 XLSX 格式，大小限制在 50MB 以内。
4. 字段映射关系（Mapping Rule）：用户建立的“导入文件列名”与“系统环境属性”的对应关系，包含必填字段（环境名称）与选填字段（代理、Cookie、标签分组、备注）。

【页面功能说明】
1. 模板下载：提供标准导入模板下载，支持 CSV 和 Excel 格式。
2. 文件上传与状态读取：支持文件拖拽或点击上传，检测上传状态，并可清除已上传文件重新选择。
3. 全局规则配置：
   - 指纹分配策略：全部随机生成（BrowserForge）、使用默认模板；表格内自定义指纹参数为 Phase 2。
   - 代理匹配策略：控制如何关联代理（按 IP:Port 自动匹配现有代理库、根据表内信息直接创建新代理并绑定、或暂不绑定）。
4. 字段映射对齐：展示系统预设字段的映射状态（自动对齐/手动选择），允许通过下拉菜单将文件列头与系统属性进行关联绑定。
5. 校验结果过滤与数据预览：
   - 支持按“全部”、“正常数据”、“异常报错”过滤数据列表。
   - 列表展示解析后的序号、校验结果状态（校验通过/格式错误）、环境名称、关联代理明细、Cookie 状态、标签以及异常说明。
6. 分页控制：支持对解析出的预览数据进行上一页和下一页的分页查看。
7. 进度统计展示：在底部控制条中显示当前文件校验的读取进度百分比，并提供成功行数与异常行数的实时统计。
8. 确认入库与重新上传：支持清除当前数据并重新上传，或点击确认，仅将校验通过的环境列表导入系统数据库。

【数据与状态流转】
1. 上传与解析流转：用户上传文件后，系统处于“文件读取中（进度百分比递增）”状态，后端对文件进行数据预解析并验证。
2. 映射与规则更新流转：当用户修改“全局规则”或“映射关系”后，后端需重新执行数据校验逻辑，页面重新加载解析预览与校验报告。
3. 校验状态分流：数据经过格式校验后被分类为“校验通过”与“格式错误”（如有格式错误的代理地址或非法的 Cookie 文本）。
4. 确认入库流转：确认导入后，系统会过滤掉标记为“格式错误”的无效数据行，仅将“校验通过”的数据生成对应的环境（Profile）记录写入数据库，并在需要时联级创建新代理。

【异常与边界情况】
1. 文件大小超限：上传的文件大小如果超过 50MB，后端应拒绝解析并抛出相应的超限错误。
2. 必填字段缺失：当字段映射关系中，“环境名称”未绑定任何表格列，或者表格内对应列的单元格值为空时，对应行应标记为格式错误。
3. 关联代理格式错误：若表格中代理字段不满足格式规范（如 `socks5://invalid_ip` 缺少端口配置），需将其标记为“格式错误”并输出异常说明。
4. Cookie 格式非法：若 Cookie 列数据不是标准 JSON 格式或 Base64 密文格式（如直接填入了普通字符串），需将其标记为“格式错误”并输出异常说明。
5. 脏数据处理：点击“确认导入并入库”时，后端需确保不会将异常报错的行写入数据库；对于重复导入的防重机制，当前页面未体现，无法从当前页面确定。

【对后端理解最重要的支撑点】
1. 异步或预解析设计：由于大文件导入可能需要耗费较多算力，页面设计有明显的百分比进度指示（“75%”）和“预解析前50行”的说明，后端需要支持对大文件的异步解析与校验，或分片读取并回传实时状态。
2. 动态校验机制：修改全局策略（指纹、代理）与映射关系时，后端应当能够重新应用映射并更新校验状态。
3. 连带业务操作：创建环境时需根据“代理匹配策略”，自动查询已有代理或创建新代理实体，且需要根据“指纹分配策略”决定如何生成或选用 Camoufox 的指纹配置文件。
