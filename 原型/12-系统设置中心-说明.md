# 系统设置中心 页面说明

- 会话：# Camoufox 控制台 UI 功能设计
- 页面角色：子页面
- 导出时间：2026/7/29 22:52:59

【页面职责】
本页面为系统设置中心，主要用于对控制台客户端进行全局参数配置、管理浏览器环境的本地存储卷及目录迁移、维护和下载 Camoufox 浏览器版本（全局 Active），以及同步 GeoIP 数据库。

【业务对象】
一、 全局配置对象：包含客户端语言、系统主题、默认环境启动模式、主窗口关闭行为、开机自启开关。
二、 存储路径与空间对象：包含 Profile 根目录路径，磁盘使用占比、环境数据目录占用、缓存垃圾体积。
三、 Camoufox 版本对象：各 build 的安装状态、Active 标记、磁盘占用、下载进度。版本通过 `multiversion.py` 全局管理，非 per-Profile。
四、 GeoIP 数据库对象：当前数据库来源、版本号、校验时间。

【页面功能说明】
一、 常规配置管理：语言、主题、默认启动模式、关闭主窗口行为、开机自启。
二、 存储与空间管理：Profile 根目录、打开目录、磁盘占用、清理缓存。
三、 Camoufox 版本管理：同步远程版本列表、安装/卸载 build、设为 Active（全局运行版本）。对齐 `camoufox gui` 能力。
四、 GeoIP 数据库管理：从远程源同步 GeoIP 数据库、打开 GeoIP 目录。不支持手动上传 .mmdb 文件（与 camoufox geolocation 模块一致）。

【关键用户动作与业务含义】
一、 保存设置：持久化常规参数。
二、 更改 Profile 路径：更新根目录（运行中实例时需阻断）。
三、 刷新远程列表 / 安装：同步 GitHub releases，下载 Camoufox build。
四、 设为 Active：切换全局运行版本，所有环境启动时使用该 build。
五、 从远程源同步 GeoIP：调用 `geolocation.download_mmdb()`。

【数据与状态流转】
一、 Active 版本唯一：设为 Active 后，原 Active 版本降级为已安装未 Active。
二、 下载中状态：显示进度与速度，完成后变为已安装。
三、 Active 版本不可卸载。

【对后端理解最重要的支撑点】
1. Camoufox 版本为全局配置，不在环境级别管理。
2. GeoIP 从远程 repo 同步，非用户上传。
3. Local API 端口状态可在此页展示关联信息。

【页面关系与流程承接】
默认启动模式与 Profile 根目录作为「新建环境」的默认参数；Active Camoufox 版本作为所有环境启动时的执行二进制。
