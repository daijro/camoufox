1. 基础特征配置

指定操作系统平台。User-Agent 与 Firefox 版本由 Camoufox 启动时自动生成。

由 BrowserForge 根据 OS 与已安装 Camoufox 版本自动推导。

2. 屏幕与窗口渲染

控制屏幕分辨率、设备像素比 (DPR) 以及视口偏移防检测策略。

3. 地理定位与 WebRTC

配置代理 IP 联动设置，防范因时区和网卡真实 IP 泄露关联风险。

基于代理出口 GeoIP 动态校准浏览器系统时区
优先采用代理服务器属地常用语言注入 Headers

4. 指纹噪声 Seed 策略

Canvas、Audio、字体 spacing 的 seed 在 Camoufox 启动时注入 C++ 层。

canvas:seed — 启动时随机
audio:seed — 启动时随机
fonts:spacing_seed — 启动时随机
