# 代理管理中心 页面说明

- 会话：# Camoufox 控制台 UI 功能设计
- 页面角色：子页面
- 导出时间：2026/7/29 22:52:59

【页面职责】
本页面为“代理管理中心”，主要负责管理和维护指纹浏览器系统中的所有网络代理资产。其核心业务职责是确保代理的可用性，维护代理的连通状态与地理位置信息（GeoIP），并管理代理与浏览器环境（Profile）之间的绑定与分配关系，从而为浏览器环境的安全隔离提供底层网络通路支撑。

【业务对象】
1. 代理网络资产：关键属性包括代理别名、协议类型（如 SOCKS5、HTTP、HTTPS）、连接地址（包含 host、port、用户名、脱敏后的密码）、实际出口 IP、国家地区位置（基于 GeoIP 推导）、连接延迟、状态（正常、异常/超时）、关联的环境数量以及最新检测时间。
2. 环境：在此页面作为代理的关联目标出现，主要关注其名称、运行状态、最近运行时间以及与当前代理的绑定/解绑状态。

【页面功能说明】
1. 代理状态仪表盘：展示全局可用代理比例、平均连通延迟、以及正常与异常代理的数量摘要。
2. 检索与筛选：支持根据代理别名、出口 IP、连接地址进行搜索；支持按协议类型、延迟范围（极速、中等、高延迟、超时）以及归属国家进行多维度过滤。
3. 代理单条新建与测试：提供单条录入代理参数的表单，并支持在保存前触发连通性测试。
4. 批量导入：支持文本粘贴（如 ip:port:user:pass 格式）与 CSV 模板文件上传，并可配置导入后是否自动执行延迟测试与国家归属识别。
5. 批量与单条连通性测试：支持对单条代理或选中的多条代理发起即时的网络延迟和出口 IP 检测。
6. 批量删除失效代理：允许一键清理所有被检测为异常或超时的代理。
7. 详情展示与反向绑定抽屉：展示所选代理的详细物理参数与当前关联的环境列表；支持在此将代理一键反向分配给其他未绑定代理的环境，或解除与当前环境的关联。

【关键用户动作与业务含义】
1. 新建/保存代理：将新的代理服务器配置持久化到数据库。
2. 开始检测/批量连通性测试：触发后端对指定代理的网络探测，更新代理的生存状态、延迟、实际出口 IP 及地理位置信息。
3. 解析并批量保存：后端需解析用户输入的非结构化文本或 CSV 文件，验证格式并批量存入数据库，同时根据勾选的导入行为异步触发测试与 GeoIP 解析。
4. 解绑：解除指定代理与指定浏览器环境的关联，使该环境失去代理通路，恢复为未绑定状态。
5. 确认绑定此代理（反向分配）：将当前代理强制关联到选中的浏览器环境，并在环境中记录该绑定关系。
6. 删除/批量删除失效代理：从系统中物理或逻辑删除代理，需要清理相应的环境关联关系。

【数据与状态流转】
1. 代理状态流转：代理被录入后处于“待检测”状态（或页面呈现的“未检测/未知归属”），测试成功后流转为“正常”（绿色标识，记录延迟与出口 IP ），测试失败流转为“异常/连接超时”（红色标识）。出口 IP 可能会随着动态代理的测试发生变更，需每次测试后更新。
2. 绑定关系流转：在右侧抽屉进行“确认绑定”或“解绑”操作时，代理的“关联环境数”及对应环境的“绑定代理 ID”会发生即时改变，未绑定的环境在列表中会被标记出来供分配。
3. 导入数据流转：用户输入的原始文本/CSV 转换为结构化代理数据，流向数据库，随后根据行为配置流向异步的网络探测任务，最后将探测结果（出口 IP、延迟、时区）反写回数据库。

【异常与边界情况】
1. 引用中删除：当用户删除某条代理（或批量删除失效代理）时，该代理可能正被环境关联使用（关联环境数 > 0）。后端需处理此边界，是拦截删除，还是允许删除并同步将关联环境的代理设置置空，需后端根据业务规则做安全处理。
2. 密码脱敏与解密：列表和详情中展示的密码必须脱敏，但后端在执行“连通性测试”或启动浏览器实例时，必须能够解密并使用真实的用户名和密码。
3. 批量探测的网络拥堵：当用户触发“批量连通性测试”时，若代理数量巨大，后端需进行并发控制与超时管理，避免阻塞服务器网络带宽。

【对后端理解最重要的支撑点】
地理位置与环境指纹对齐：页面明确提到“重新绑定代理后，关联的环境将在下次启动时，强制要求对当前 IP 与环境指纹的地理位置（如时区、经纬度）实施自动对齐策略”。这意味着代理的探测结果（如 GeoIP 的时区、经纬度、国家）不仅仅是展示信息，更是浏览器环境启动时 C++ 层指纹注入的重要输入参数。后端在执行代理检测时，必须保证获取的时区和地理位置数据精准、结构化，以便下游指纹生成模块（M3）调用。

【页面关系与流程承接】
1. 上游输入：本页面是代理数据的入口。用户在此建立验证通过的“代理资源池”。
2. 下游消费：
   - 当用户在“环境管理”（M1）的新建环境向导中选择“从代理库选择”时，数据源即来自本页面。
   - 当环境启动时，Camoufox 将读取此处保存的代理主机、端口和解密后的凭据来建立隧道。
   - 本页面的“反向分配”可直接将代理分发给环境管理模块中的 Profile，无需用户切换页面。
